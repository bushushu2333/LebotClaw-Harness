# LebotClaw Harness v0.2.1：交互整改与真实验收

日期：2026-09-26。仅修改本机项目和本地服务，没有远端部署。

## 问题与定位

用户截图中的打砖块任务未能回复普通问候。GLM 配置的地址是 `/api/anthropic`，运行器却发送 OpenAI Chat Completions 请求。服务端返回 HTTP 200、JSON `code:500, msg:404 NOT_FOUND, success:false`，旧解析器访问不存在的 `choices` 后仅显示“无法解析模型响应”。此前验收只覆盖了另一套正确配置，没有验证这条真实失败路径。

已加入协议地址检查、HTTP 200 业务错误处理和清晰提示；这台机器的 GLM 地址修正为 `https://open.bigmodel.cn/api/paas/v4`。未打印或写入仓库任何 Key。

## 对照依据

- [DSH 官方 Web UI 指南](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/index.md)：配置模型、选择工作区、发起会话，执行中处理授权。
- [中文社区的首次使用教程](https://deepseekdsh.com/zh/guides/web-ui)：用真实文件而非聊天中的完成声明验收结果。此站是独立社区，不是官方。
- 本机安装的 DSH `0.1.5-rc.3`，使用隔离的临时配置目录实际打开：首次 Key 引导、工作区选择、居中的对话入口、侧栏会话、设置入口。

## 改动后的使用顺序

**连接模型 → 选择项目 → 对话与方案 → 明确授权 → 制作与检查 → 打开作品。**

- 没有项目文件时只显示对话；生成成果后才展开文件和预览，可随时收起。
- 首次配置只有一个主要动作：保存并测试。测试同时检查普通对话和工具调用；修改表单后旧的成功提示失效。
- Key 不可用时给出配置入口；不会仅凭已保存一个模型名称就开放发送。
- 新项目从 Plan 开始。打开制作授权时明确展示范围；确认前不会执行；可选择授权后立即接着上一条需求制作。
- 临时授权结束后，状态明确回到 Plan，不保留“可以开始制作”的成功横幅。
- 运行中显示当前工作和逐步回复；操作日志默认收起；失败原因直接显示，并提供重试与配置入口。
- 提供本机文件夹浏览、项目目录打开、单文件下载和完整项目 ZIP。目录与文件打包仍遵守项目读取授权。
- 窄窗口有项目列表入口，避免隐藏侧栏后无法切换任务。

## 本轮真实模型验收

文字服务：GLM `glm-5.3`，官方 OpenAI 兼容地址。生图服务：已配置的 Seedream。

1. 在原失败任务中点重试，“你好呀，你可以做什么呢”获得真实回复。
2. 在浏览器输入太空打砖块需求，先 Plan，获得方案。
3. 从界面点「授权并继续」，开启项目读写与生图，保持命令执行关闭，点「授权并开始制作」。
4. 自动模式中批准一次星空背景生成请求。
5. Harness 自己调用 `files_list → image_generate → file_write → browser_check → file_patch → browser_check`。第一次浏览器检查发现暂停遮罩挡住按钮；模型自行调整层级并重新验证。
6. 本轮 7 次模型调用，约 123 秒，45,167 token，正常结束。生图请求 1 次；第二次浏览器检查返回 `browser_checks_passed`。
7. 独立打开游戏实际点击开始、暂停、继续、重新开始：分数从 0 变为 20，生命减少，重开恢复 0 分、3 条命；未看到浏览器脚本错误。没有手写或手改游戏代码。

游戏：桌面 `LebotClaw Harness v0.2 验收/星际打砖块/index.html`。与 `assets` 文件夹一起保留后可本地打开。

完整轨迹：桌面 `LebotClaw Harness v0.2 验收/打砖块-真实运行记录.json`。其中也保留首次检查失败与随后修复的记录。

## 自动验证与实际限制

40 项自动测试通过，覆盖模型协议错误、无工具普通对话、失败首次请求修正配置后继续原任务、权限拦截与撤销、模型 Key 就绪状态、目录浏览及项目 ZIP 等；JavaScript 语法检查通过。

这是本轮经过验证的交互和制作闭环，不等于已达到 DSH 或 Claude Code 的全部能力。MCP、长上下文压缩、后台开发服务、通用 OCR 尚未完成；ASR/TTS 本轮没有真实服务验收。游戏本轮验证了启动、暂停、恢复、重开及计分生命变化，没有穷尽所有碰撞和通关情况。

本机演示 Key 仍只在当前进程内存中；服务关闭后需重新输入，或由用户在设置里选择保存到系统凭据库。临时项目授权重启后失效；查看旧项目文件时可只授予读取权限。
