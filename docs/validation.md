## 已通过的自动化检查

`python -m pytest -q`：**19 passed**。

- 关闭运行时后再次打开，原会话可继续；完整模型协议字段保留。
- 排队阶段和请求进行中均可取消，项目写锁释放。
- 写入途中取消会把未完成工具结果标为未知，补齐协议；重启恢复不重复写入。
- 步数预算停止、更换提供商/型号的协议保护、数据目录进程锁。
- JSON Schema 校验、路径越界、符号链接、隐藏目录、覆盖哈希冲突、特殊文件拒绝。
- 程序执行不继承测试密钥环境变量；超时和取消后，测试子进程不会写出延迟文件。

- 模型断流/长度截断不执行部分工具；HTTP 错误不回显服务商返回的秘密文本。
- Web API 来源和令牌校验；真实文件读取与 JSON 存储；模型 Key 不落配置文件，换服务地址不会复用原内存 Key。
- 单次模型输出预算和推理强度传到提供商；配置范围校验；图形界面基本设置保存保留高级预算。

## 真实模型生成验收

已使用获得授权的 GLM-5.3 API Key，通过智谱官方通用 API 完成工具连接验证，并让实际 Harness 从空目录生成田忌赛马 HTML、独立 Mac 应用及测试、构建源码。经预算参数修正、外部反馈和多轮续跑，25 项逻辑测试、六种排列实际点击、独立应用三局动画和严格验签通过。过程不是一次指令零干预成功；游戏代码由 Harness 自行写入和修复。见 [完整结论](../examples/tianji-autonomous/RESULT.md)。

## 已通过的界面操作

通过浏览器自动化实际点击、填写和观察，使用独立临时数据目录及显式标记的测试模型：

1. 在表单保存本机兼容接口配置。
2. 从输入框发起任务，共用 Runtime 调用文件工具，产生 `index.html`，展示真实工作记录。
3. 打开隔离预览，点击按钮，经 `lebot.save` 保存数据。
4. 刷新并重开作品，通过 `lebot.load` 恢复先前计数值。
5. 作品访问父页面被浏览器阻止，预览内 `fetch` 被 CSP 阻止。
6. 检查桌面三栏与窄窗口布局，窄窗口保留历史任务选择入口。
