# LebotClaw Harness v0.2 验证记录

日期：2026-09-26。环境：macOS Apple Silicon，Python 3.9.6，Playwright 1.58 / Chromium。仅在本机开发与测试，没有部署远端环境。

## 自动化测试

覆盖以下流程：

- 真实本地 HTTP/SSE 传输、工具协议保留、CSV 读取/写入/执行/报错修复、会话恢复。
- 默认 Plan 下，即使模型强行返回工具调用，也不落盘。
- 逐次批准前无副作用；批准、拒绝、失效 ID、临时授权到期、撤销待批准任务。
- 记住项目授权与新项目默认 Plan；本机命令独立确认。
- API Host/Origin/令牌校验；读取授权前不暴露项目文件列表。
- 主模型配置与图片配置隔离；失败更新不半写配置；密钥不进入普通配置文件。
- Images HTTP 结果转成真实 PNG，回填后再由模型写入 HTML 引用；图片请求数预算。
- 万相 SSE 收到完整结果后立即结束，不等待 EOF；协议测试不等于万相线上服务稳定。
- PPTX/DOCX 真实生成、正文可读取、图片嵌入、文本补丁和原版本保存。
- 多文件 HTML/CSS/JS/图片真实运行；表单提交、点击、保存、刷新恢复、JSON 下载和截图。
- 项目预览来源互相独立，重启复用端口、旧访问令牌失效；撤销后不能继续读取资源。
- ASR multipart 与 TTS MP3 请求/响应、认证头隔离，使用模拟接口。
- 取消时回收命令进程；图片地址不能指向本机/内网；符号链接与越界路径拒绝。

执行命令：`.venv/bin/python -m pytest -q`。最终结果见本文件末尾的构建记录。

## 真实模型验收

**任务**：制作周一至周五、每天六节的动态课程表，支持编辑课程和教室、保存/刷新恢复、导出 JSON；生成真实校园插图，并制作含图的三页可编辑使用说明 PPT。

**入口**：产品正式的 `/api/session`、`/api/run` 和独立 `/api/permission` 接口，随后在同一浏览器产品界面查看。不是测试脚本伪造的模型决定，也没有预置课程表模板。

**主模型**：GLM `glm-5.3`，官方接口，经本机已有配置提供 Key；文字连接与工具调用探测成功。

**生图**：智云网关。万相 `wan2.6-image` 返回明确服务端 `InternalError.Algo <500>`；人工切换可选生图配置为 `Doubao-Seedream-5.0-lite` 后，Harness 单次调用成功，保存 2848×1600 的 PNG。

### 人工介入如实记录

本次不是从头到尾一次无人介入通过：

1. 开发者配置真实模型与 Key，并为新建的验收目录授予有限的文件/生图权限；未授予系统命令执行。
