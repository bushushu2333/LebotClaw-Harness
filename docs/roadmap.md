# v0.2 后续执行清单

这一轮已完成本地浏览器入口、自带 Key、多模态配置、四种授权模式、真实素材接入、多文件预览、可编辑文档和浏览器交互验证。任务质量仍取决于模型、材料、依赖及已授予的权限。

## 下一轮优先工作

1. **LebotAPI 真正联调**：确认实际部署地址与 API 协议，接模型目录、个人 Key 可用乐豆额度和任务用量查询；服务端实施充值、预留、结算、退款、幂等与对账。客户端不自造余额。价格规则固定官方价 95 折。
2. **持续复杂任务**：上下文压缩与检查点、可恢复工具队列、持久开发服务管理、项目全局锁，减少长任务预算中断。
3. **工具生态**：MCP 与受信任技能、更多国内模型专有协议、异步生图任务查询、视觉检查与 OCR。
4. **作品质量**：PPT 渲染检查和布局修正、浏览器下载/刷新/存储断言、图片编辑与角色一致性、多文件工程构建。
5. **发行体验**：跨平台一键安装、Docker 依赖与镜像准备、权限沙箱审计、回滚 UI、签名发行、自动更新。
6. **发布验收**：按 PRD 的任务通过率、质量、预算与人工介入标准，形成可复跑的公开评测；协议模拟测试不替代真实模型任务验收。

本轮真实验收和限制见 [v0.2 验证记录](validation-v0.2.md)。
