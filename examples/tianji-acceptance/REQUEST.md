# 田忌赛马 · Harness 真实任务验收

## 目的

验证 LebotClaw Harness 通过真实模型自主调用工具，从需求生成可玩的本机成果。没有真实模型调用时，不能用手写游戏、脚本模型或预置模板替代这项结论。

本轮用户要求两份产物：
1. 单文件 `田忌赛马.html`，离线双击即可玩。
2. 当前 Apple Silicon Mac 上可独立打开的 `田忌赛马.app`，包含游戏资源，无需先启动 Harness 或本机网站。

## 发给模型的需求

你是超级小博。请从零制作一个面向青少年的「田忌赛马」策略小游戏，并交付可玩文件。

- 单文件 HTML，内联 CSS/JS/SVG，无 CDN、远程资源、fetch、npm 或服务器依赖。普通浏览器 file:// 打开、Harness 预览和 macOS WebKit 均可玩。不依赖 lebot 接口；如用本机存储，失败时仍能正常游戏。
- 我方三匹马：上等马速度 90、中等马 70、下等马 50；齐王三匹马：上等马 100、中等马 80、下等马 60。这是为游戏设计的数值。
- 经典挑战：齐王依次派上、中、下等马。玩家安排己方三匹马的出场顺序，每匹只能出场一次，三局累计胜两局获胜。
- 明确展示双方马匹和速度、当前出场顺序，允许在开赛前调整。顺序没排完不能开赛。对局进行时不能修改阵容。
- 有实际赛马动画，胜负根据速度确定。每场结束更新比分、说明结果；整场结束给出结果和策略解释，可以再玩、重排、查看提示。支持跳过动画，不重复结算。
- 优先做清晰、有趣、流畅的游戏，不做聊天模拟页。紫蓝为主要操作色，浅色场景，文字清晰，正文不少于 14px，按钮不少于 44px。适配窄窗口并支持键盘操作。
- 不要一开始替玩家选好获胜阵容；提示可由玩家主动查看。
- 游戏逻辑与绘制分离，提供纯函数以便验证所有排列。至少验证同等级对阵 0:3、下/上/中排列 2:1、6 种排列不存在重复使用马匹、重新开始状态清空、跳过动画只结算一次。
- 输出 `田忌赛马.html`、可运行的逻辑验证脚本和简短使用说明。不要只给代码段，不宣称未经执行的测试通过。
- 本目录提供的 `macos/build_app.py` 是通用离线 HTML 打包工具，不含游戏逻辑。完成 HTML 后可运行它，创建真实 `.app`。如命令执行未开启，明确报告缺失条件，不伪称已构建应用。

## 人工验收

- [ ] 真实模型、配置名称、运行 ID 与工具记录可追溯。
- [ ] 全新目录由模型生成游戏内容，无提前放入完整游戏。
- [ ] 单文件打开，排阵、赛马、结算、再玩正常。
- [ ] 同等级出场输 0:3；下/上/中出场赢 2:1。
- [ ] 重复点击、跳过、重新开始不会重复加分或残留上一局状态。
- [ ] `.app` 实际启动并完成一整场比赛。
- [ ] HTML 与 `.app` 内打包文件 SHA-256 相同。
